# Claim Boundary

## Supported description

PAIL is a prototype evidence-control middleware and neuro-symbolic research
runtime. It combines deterministic identity/relation guards, bounded evidence
packing, contradiction persistence, adaptive verified memory, and optional
learned or acoustic candidate-routing components.

## Do not claim

- that symbolic sound equals semantic understanding;
- that wave storage replaces databases;
- that the published examples implement thousands of executable sutras;
- that token reduction automatically means answer quality;
- that synthetic benchmark results establish production readiness;
- that the system is conscious or is AGI;
- that root-cause correlation proves causality.

## Research hypothesis

A typed hybrid runtime can let deterministic evidence rules, adaptive memory,
learned representations, and external tools cooperate while preserving
provenance and preventing learned components from silently overriding verified
facts.
